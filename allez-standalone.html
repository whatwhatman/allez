接入模型（可选）

没有 Key 也能用。离线规则引擎负责抽词、CEFR 分级、易错点检测和变位练习。接入 Key 后，中文释义会自动补齐并校准、真题式完形和阅后的写作批改由模型完成。Key 只存在你的浏览器 localStorage，直接打到你选的接口地址。
为什么接了模型会强很多

三件事离线做不了：① 给每个词生成贴合你上下文的中文释义，而不是词典冷冰冰的义项；② 生成真正的「受限文本」——严格控制在已学词汇 + i+1 范围内的法语短文，这是词汇自然复现的关键；③ 对你主动输出的法语做 CEFR 级批改（语法、性数配合、语体），而不只是找拼写。

扫描件识别（OCR）

两种引擎各有权衡：视觉模型质量最好、重音还原准，但需要 API Key，且图片会发给你配置的接口；Tesseract.js 在你浏览器本地跑、图片不出本机，但首次要从 CDN 下载约 15 MB 模型，且法语重音容易丢。

数据备份

所有学习数据都在你这台浏览器里，清缓存、换浏览器、换设备都会丢，而且找不回来。下面这个按钮会把全部进度导出成一个 JSON 文件，换设备时再导回来就行。

关于这个原型

技术：纯静态 HTML + 原生 JS，无构建、无依赖。调度算法用 SM-2 简化版，建议正式版换 FSRS（Anki 的新算法，对「每天能学几分钟」这种现实约束友好得多）。语音用浏览器自带的 fr-FR 合成，正式版建议换 Azure 法语神经语音或 ElevenLabs。
